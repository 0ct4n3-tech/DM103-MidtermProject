1. Install NodeJS -- LTS
2. Have a MySQL80 running(services.msc)
3. replace the username, password according to your MySQL in server.js and script.js
4. open terminal and cd ..(to the folder) type "npm install"
5. in the same directory/workspace type on terminal "node server.js"

how to start:
1. Start MySQL
2. Start Node server.js
3. run main.html
